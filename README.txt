RUKHSAR — OFFLINE MEMORY EXPERIENCE

1. Keep the entire folder together.
2. Open index.html in a browser.
3. The site is designed to work without internet.
4. Photos are inside assets/images/.
5. The uploaded video is inside assets/videos/.
6. The local soundtrack is inside assets/audio/.
7. To replace the soundtrack, replace assets/audio/video-soundtrack.mp3 with your own MP3 and keep the same filename.
8. For stronger privacy, put the finished folder inside an AES-256 encrypted ZIP before sharing it.
